# Images

Drop screenshots and diagrams here, then reference them from a page with a relative path:

```markdown
![Debug overlay in flight](assets/images/debug-draw.png)
```

Pages currently mark spots where a screenshot helps with a **"📷 Screenshot"** callout naming the suggested
filename - capture the shot, save it here under that name, and replace the callout with an image embed.

Suggested captures referenced by the docs:

| Filename | Page | Shows |
|---|---|---|
| `workbench-project.png` | Getting Started | PFC project loaded in the Resource Browser |
| `debug-draw.png` | Getting Started | F6 debug overlay in flight (force arrows + data panel) |
| `surface-forces.png` | Flight Model | Per-surface force arrows + magenta surface extents |
| `prefab-components.png` | Prefab Setup | Cessna172 prefab component tree in the inspector |
| `variant-surfaces.png` | Building a Variant | A new airframe with surface extents drawn |

Keep images reasonably sized (e.g. ≤ 1600 px wide, PNG or JPG) so the site stays light.
